# Los hijos del Fundillo

Addon de **WoW Forever** para la hermandad **Los hijos del Fundillo**: pedidos y ofertas entre
miembros, pedidos de la hermandad, quedadas de mazmorra y más. *¡Mi vida por el fundillo!*

## Instalación

1. Descarga **`HDFprofesiones-vX.Y.Z.zip`** en **Releases** (columna derecha de esta página).
2. Descomprímelo dentro de `World of Warcraft\_forever_\Interface\AddOns`.
   Debe quedar `AddOns\HDFprofesiones\HDFprofesiones.toc`.
3. Si tenías una versión anterior, borra antes la carpeta `HDFprofesiones` vieja.
4. En la pantalla de personajes, pulsa **AddOns** y comprueba que *Los hijos del Fundillo* está activado.

## Cómo se abre

Ventana de hermandad (**J**) → pestaña del **engranaje** en su borde derecho. Al abrirlo, el
**Inicio** explica cómo funciona cada parte.

Todos los de la hermandad deben tener **la misma versión**: la información viaja entre los que
están conectados.
